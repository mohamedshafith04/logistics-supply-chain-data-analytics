## Logistics & Supply Chain Data Analytics

Python-based data analysis and visualization project focused on understanding logistics and supply chain operations.

## 📌 Project Overview

This project analyzes logistics data across different operational areas including customers, loads, routes, trucks, trailers, drivers, fuel, maintenance, facilities, safety, and trip performance.

The main objective is to transform operational data into meaningful business insights using Python-based data analysis and visualization.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis & Visualizations

The project includes 12 visualizations organized into 3 dashboard canvases.

Key areas analyzed:

- Truck fuel tank capacity
- Facility dock door capacity
- Trailer model year distribution
- Route distance and pricing
- Load type and cargo weight
- Customer revenue potential
- Trailer allocation by location
- Driver workforce analysis
- Driver experience by terminal
- Facility geographic distribution
- Truck acquisition mileage

## 📈 Dashboards

The analysis is presented through 3 dashboard canvases, with 4 visualizations in each dashboard.

These dashboards provide a consolidated view of different logistics and supply chain operations.
